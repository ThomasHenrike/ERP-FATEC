# MERP — Tipografia

Família única: **Inter** (Google Fonts, licença SIL Open Font License).
Download: https://fonts.google.com/specimen/Inter

Pesos usados: Regular 400 e Medium 500. Títulos nunca passam de 500 — a hierarquia vem de tamanho e espaço.

| Estilo | Peso | Tamanho / entrelinha | Observação |
|---|---|---|---|
| Título | Medium 500 | 33 / 40 px | |
| Subtítulo | Medium 500 | 21 / 28 px | |
| Corpo | Regular 400 | 15 / 26 px | |
| Etiqueta | Medium 500 | 11 px | caixa alta, entreletra 0.22em |
| Números | Medium 500 | conforme contexto | font-variant-numeric: tabular-nums |

## Logotipo

A palavra MERP é Inter Medium 500 em caixa alta, entreletra 0.15em. O descritivo MODULAR ERP é Inter Medium 500, entreletra 0.28em, em cinza 500.

## CSS

```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500&display=swap');
body { font-family: 'Inter', system-ui, sans-serif; }
```
