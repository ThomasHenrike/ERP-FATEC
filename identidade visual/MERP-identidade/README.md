# MERP — Identidade visual v1.0

ERP modular para empresas controlarem vendas e estoque.

O símbolo são três blocos de mesmo tamanho em degrau; o bloco verde é o módulo ativo. A folga entre os blocos faz parte da marca — nunca encoste os blocos.

## Conteúdo da pasta

- **MERP-guia-de-marca.html** — o guia completo. Abra no navegador; para PDF, use Imprimir → Salvar como PDF.
- **logos/png/** — PNG com fundo transparente, em três resoluções (tamanho no nome do arquivo).
- **logos/svg/** — versões vetoriais. As que têm texto usam a fonte Inter: instale-a antes de abrir em editores (Illustrator, Figma) ou converta o texto em contorno.
- **cores/** — paleta em Markdown, CSS (variáveis) e JSON.
- **tipografia/** — família, pesos e escala.

## Qual logo usar

| Arquivo | Uso |
|---|---|
| merp-horizontal | Padrão: cabeçalho do sistema, e-mail, documentos (fundo escuro) |
| merp-horizontal-claro | Mesma assinatura sobre fundo claro |
| merp-vertical | Espaços estreitos, tela de login |
| merp-simbolo / -claro | Menu recolhido, avatar |
| merp-icone-app | Ícone de aplicativo (único com fundo próprio, verde 900) |
| merp-favicon | Favicon do navegador |

## Construção e respiro

- Grade de 48 × 48; blocos de 17, folga de 4, raio 3.
- Respiro mínimo: a largura de um bloco (35% da altura do símbolo) em todos os lados.
- Tamanho mínimo: 24 px de altura para o símbolo isolado; 18 px de altura de símbolo na assinatura horizontal.

## Não faça

- Não gire, incline nem aplique perspectiva no símbolo.
- Não troque a cor do bloco ativo.
- Não aplique gradiente, sombra ou contorno.
- Não use sobre foto sem área de valor uniforme.
- Não engorde o texto MERP acima do peso 500.
